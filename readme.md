# Ministero del Modem

Portale istituzionale non richiesto per la gestione delle emergenze digitali, delle stampanti offese, delle pause caffè inevitabili e dei computer che decidono di non collaborare proprio quando hai fretta.

Il progetto ricrea l’estetica dei siti pubblici e dei programmi per Windows dei primi anni 2000: grigio Windows 98, bordi tridimensionali, finestre trascinabili, avvisi inutilmente solenni e documenti ufficiali che non hanno alcun valore legale.

Per fortuna.

## Cosa fa

* Genera certificati provvisori di impedimento digitale
* Crea protocolli casuali in stile ministeriale
* Permette di scegliere la motivazione della pratica
* Permette di impostare il livello di gravità
* Mostra una barra di avanzamento assolutamente necessaria
* Genera testi casuali per evitare che due certificati siano identici
* Permette di copiare il certificato negli appunti
* Permette di stampare il documento dal browser
* Include una finestra trascinabile in perfetto stile desktop anni 2000

## Esempi di motivazioni valide

* Il computer non collabora
* Il modem ha fatto rumori sospetti
* Il Wi-Fi è connesso solo spiritualmente
* La stampante ha deciso di non parlare
* Smarrimento improvviso della voglia di fare
* Presenza di troppe schede aperte nel browser
* Aggiornamento Windows senza fine apparente
* Pausa caffè di emergenza non rinviabile

## Tecnologie usate

Il progetto è costruito con tecnologie moderne, anche se prova con molta convinzione a sembrare uscito da un CD-ROM del 2003.

* HTML
* CSS
* JavaScript

Non usa framework, database, backend, login, server, WebSocket, blockchain o altre cose che avrebbero reso il Ministero inutilmente efficiente.

## Avvio locale

Clona la repository:

```bash
git clone https://github.com/TUO-USERNAME/ministero-del-modem.git
```

Entra nella cartella:

```bash
cd ministero-del-modem
```

Apri `index.html` nel browser.

Non serve installare nulla. Il portale è più semplice da avviare di molti software realmente utilizzati negli uffici.

## Struttura del progetto

```text
ministero-del-modem/
├── index.html
├── style.css
├── script.js
└── README.md
```

* `index.html` contiene il portale, i campi del modulo e il certificato;
* `style.css` gestisce il gusto discutibile ma istituzionale dell’interfaccia;
* `script.js` genera protocolli, testi casuali, barra di elaborazione e funzioni di stampa;
* `README.md` cerca di giustificare l’esistenza del progetto.

## Funzione stampa

Il pulsante “Stampa certificato” usa la finestra di stampa del browser.

Da lì puoi:

* stampare davvero il documento;
* salvarlo come PDF;
* mandarlo a qualcuno che ha bisogno di una giustificazione vagamente credibile;
* conservarlo come prova che il modem, almeno una volta, ha avuto la meglio.

Durante la stampa vengono nascosti menu, moduli e barra delle applicazioni: resta soltanto il certificato.

## Nota istituzionale

I certificati generati dal Ministero del Modem non producono effetti giuridici, non sospendono scadenze, non giustificano assenze e non convincono il professore, il datore di lavoro o tua madre.

Possono però migliorare sensibilmente l’umore di chi li genera.
